# 배포 기록

`main`에 합쳐진 풀 리퀘스트는 곧바로 운영 서버에 배포됩니다. 풀 리퀘스트마다 저장소 루트의 `VERSION`을 올리고, 여기 맨 위에 그 버전과 바뀐 내용을 적습니다([AGENTS.md](../AGENTS.md) 7번). 게임 화면 왼쪽 아래 구석에 지금 접속한 배포의 버전과 커밋이 표시됩니다.

## 0.17.3

- 여관 NPC 다섯 명을 원본 스프라이트(영웅 갑옷 단계 그림과 상점 주인)를 바탕으로 다시 그려, 플레이어 캐릭터와 같은 비율·외곽선·명암으로 맞췄습니다. 경비병과 여관주인, 노점상은 홀 쪽(왼쪽)을 바라봅니다.

## 0.17.2

- `@claude` 멘션으로 Claude Code GitHub Action을 실행합니다. 포크 PR은 건너뛰고, 같은 이슈·PR에서는 한 번에 하나만 실행합니다.

## 0.17.1

- 동료 화면이 파티장의 실제 걸음을 한 칸씩 재생합니다. 던전 프로토콜을 15로 올렸습니다.
- 순간이동과 밀려남처럼 걷지 않고 바뀐 위치, 열두 걸음보다 많이 밀린 경우에는 그 자리로 바로 옮깁니다.

## 0.17.0

- 화면 왼쪽 아래 구석에 버전, 배포 커밋, 서버까지의 핑을 표시합니다(웹·Windows, 여관과 던전 모두).
- 버전을 저장소 루트의 `VERSION` 파일 하나로 관리하고, 배포된 사이트가 `/play/version.json`에 버전과 커밋을 알립니다.
- 클라이언트가 서버에 보내는 `ping`을 25초에서 5초 간격으로 바꿨습니다.

## 0.16.10 이전

Windows 클라이언트 빌드 번호(`inn-client/build.gradle`의 `version`)로만 관리했고, 배포마다 기록하지 않았습니다.
