# Co-Op-Pixel-Dungeon 여관

## Windows와 브라우저에서 플레이

여관 프로필에서 닉네임, 직업과 외관을 고릅니다. Windows는 같은 게임 창에서 원정에 들어가고 웹은 여관 화면 안에서 원본 엔진을 엽니다.

- **1인 원정 · 원본 ATB**는 Shattered Pixel Dungeon 캠페인 1층에서 시작합니다. 여관에서 선택한 직업, 장비와 외관을 사용합니다.
- **동료 찾기 · 원본 2인 ATB**는 매칭된 두 사람이 파티장의 원본 캠페인 1층에서 출발합니다. 파티장이 맵과 전투를 판정하고, 동료의 이동·평타와 적의 피해를 같은 원본 던전에 적용합니다. 동료도 원본 맵과 몬스터, 전리품을 보고 파티장을 따라 다음 층으로 이동합니다. 동료의 독립 장비·가방·스킬은 이후 작업 범위입니다.
- **길잡이 연습**은 원본 ATB의 연습 전용 층입니다. 길잡이와 함께 원본 이동과 전투를 연습합니다. 허수아비는 쓰러져도 다시 일어납니다. 식량 상자와 회복 도구를 클릭해 식량을 받거나 체력·행동력·허기를 회복합니다. 연습은 원정 저장과 기록에 반영되지 않습니다.
- **원본 1인 저장**에서는 기존 턴제 저장을 엽니다. 원본 ATB에서 철수하면 현재 원정이 끝나고, 다음 원정은 1층에서 시작합니다.
- 여관에서는 나무 팻말을 눌러 모집 중인 상대에게 바로 참가할 수 있습니다. **Enter**로 채팅을 열고, 마우스 휠로 확대·축소합니다.

브라우저는 여관에 입장하면 원본 게임과 시작 에셋을 미리 받습니다. 원정에 입장할 때 같은 버전의 다운로드를 이어 쓰고, 캐시된 에셋을 재사용합니다.

## 입장 프로필과 외관 추가

여관, 파티 원정, 길잡이 연습, 1인 원정에 같은 프로필 외관을 사용한다. 전사, 마법사, 도적, 사냥꾼, 결투자, 성직자의 원본 실루엣과 이동·공격 프레임을 바탕으로 머리와 옷, 장식 레이어를 합성한다. 원본 1인 게임에서 새로 시작할 때는 여관에서 고른 직업의 장비와 능력을 사용한다. 원본 저장 공간이 가득 차고 같은 직업의 저장이 없으면 이어갈 저장을 고르는 창이 열린다.

외관 옵션과 픽셀 패턴은 `web-client/scripts/generate-avatars.py`에서 관리합니다. Python 3과 Pillow로 스크립트를 실행하면 두 클라이언트가 공유하는 직업별 PNG와 카탈로그가 생성됩니다. 저장된 프로필이 동작하도록 카탈로그의 기존 ID를 유지합니다.

아틀라스는 각 행에 12×15픽셀 프레임 18개를 갖는다. 기본 그림, 옷색, 머리 모양과 머리색 조합, 장신구 순으로 행을 배치한다. 입장과 매칭 링크는 옵션 ID만 보내며, 웹과 Windows가 같은 레이어 순서로 그린다.

## 던전과 행동력

원정은 원본 캠페인의 층 생성과 테마를 따릅니다. 길잡이 연습은 원본 타일과 캐릭터를 사용하는 고정 연습 층입니다.

- **Space**나 시계 버튼으로 시간을 1배속과 0.5배속 사이에서 전환합니다. 기준 1턴은 각각 1초와 2초입니다. 파티에서는 두 사람이 같은 속도로 플레이합니다. 원본 게임 화면에서 **Z**는 자동 이동을 멈춥니다.
- 행동력 최대치는 10이며, 게임 시간으로 마지막 차감 0.5초 뒤부터 0.8초당 1을 회복합니다.
- 플레이어의 행동력이 0에 도달하면 땀을 흘리며 쉬고, 3까지 회복해야 다시 행동할 수 있습니다.
- 한 칸 이동은 탐색·적 경계에서 무료이고, 교전·추격 중에는 1입니다. 파티장의 평타 비용은 무기의 기본 공격 간격과 무기 강화를 따릅니다. 동료의 일반 평타는 1입니다.
- 원본 플레이어의 아이템과 직업 기술은 각 원본 행동의 시간 비용을 사용합니다.
- 일반 주머니쥐와 하수구 게는 행동력 6으로 시작합니다. 이동은 각각 1과 0.5, 평타는 둘 다 1을 씁니다. 행동력이 부족하면 땀을 흘리며 쉬고, 잔량이 0에 도달하면 3까지 회복해야 다시 움직이거나 공격합니다. 파티장은 동료에게 몬스터의 피로 상태를 공유합니다.
- 파티 동료는 방향키 또는 WASD로 이동하고, 적을 클릭하거나 가까운 적에게 **Q**를 눌러 평타를 칩니다. **Esc**로 여관에 돌아갑니다.

## 빌드

[원본 업데이트 검토 절차](upstream-update.md)

Windows x64에서 JDK 21을 지정한 뒤 저장소 루트에서 실행한다.

```powershell
.\gradlew.bat -p inn-client packageWindows
```

출력은 `inn-client/build/jpackage/0.16.7/NoxacPixelDungeon/NoxacPixelDungeon.exe`입니다. 실행 폴더에 Java와 게임 에셋이 포함됩니다.

원본 브라우저판은 저장소 루트에서 `.\gradlew.bat -PwebOnly html:dist`로 빌드한다. 결과는 `html/build/dist/web`에 생성된다.

기본 서버는 [여관 운영](https://co-op-pixel-dungeon.kimyc3825.chatgpt.site)입니다. 로컬 개발에서는 `NOXAC_INN_URL`로 서버 주소를 지정할 수 있습니다.

## 웹 배포

공개 저장소의 `main`에 푸시하면 GitHub Actions가 웹 여관과 던전 런타임을 빌드해 Sites에 게시합니다. 브라우저에서 제공하는 여관의 소스는 `web-client/play`에 있습니다.

[웹 배포 실행 기록](https://github.com/kimyc3825/Co-Op-Pixel-Dungeon/actions/workflows/deploy-web.yml)에서 배포가 완료됐는지 확인할 수 있습니다. Windows 패키지는 [GitHub Releases](https://github.com/kimyc3825/Co-Op-Pixel-Dungeon/releases)에 게시합니다.

## 네트워크와 전투

Sites Worker와 D1이 여관 이동, 채팅, 파티 매칭, 링크 인증과 WebRTC 시그널링을 맡습니다. 같은 프로토콜의 참가자끼리 매칭합니다. Worker 소스와 운영 설정은 별도의 비공개 저장소에서 관리합니다.

파티장의 원본 엔진이 층 생성, 충돌, 적 행동, 피해와 전리품을 한 번 처리합니다. 동료는 층 번호와 순서 번호가 있는 이동·평타 명령을 보내고, 파티장은 확인 번호와 최신 탐색 지형, 위치·체력·행동력, 표시할 전리품을 공유합니다. 층이 바뀌면 이전 층의 명령을 버립니다. 전송은 WebRTC 직접 연결을 사용하며 필요할 때 Worker가 중계합니다. Java 옵션 `-Dnoxac.inn.relayOnly=true`로 개발 중 중계를 시험할 수 있습니다.

동료가 쓰러지면 해당 원정에서 쓰러진 상태를 유지합니다. 어느 쪽이 연결을 종료하면 해당 파티 원정을 종료합니다.

여관은 `/api/v2/inn`, 연결은 `/api/v4/link`를 사용합니다. `GET /api/v4/health`로 연결 API의 준비 상태를 확인할 수 있습니다.
